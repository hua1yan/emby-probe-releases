# Emby 探针 · 安卓安装包

监控多台 Emby / Jellyfin 的安卓客户端。源码在私有仓库，这里只放安装包和更新说明。

## 下载

去 [Releases](../../releases/latest) 下最新的 `emby-probe-x.y.z.apk`。

- **首次安装**要在系统里允许「安装未知来源应用」。
- **4.48.0 换成了正式签名**，装过旧版的要先卸载再装，之后的版本都能直接覆盖升级。
- 卸载会连本机配置一起删。介意的话先在设置里导出配置，装好再导入。

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 看板 | 每台服务器的在线状态、延迟、最近检查时间、电影 / 剧集 / 单集数量；离线时显示 HTTP 状态码与归类后的原因 |
| 桌面小部件 | 直接显示最近一次刷新的那台，和 App 卡片同样的内容：服务器名、状态、三行媒体数、保号剩余、延迟、上次播放。不打开 App 也会自己更新 |
| 历史大盘 | 24 小时 / 7 天可用率、离线次数、离线时段、状态时间条 |
| 资源增长榜 | 按电影 / 剧集 / 单集排今日增长 |
| 保号提醒 | 按最近播放时间算剩余天数，临期与逾期分开提示 |
| 通知 | 掉线、恢复、保号临期三类可推送，支持按服务器免打扰 |
| 图标 | 自定义图标与内置图标包，GIF 动图也能显示 |

## 用它需要什么

一台跑着自己后端的服务（Cloudflare Workers），以及那个服务的管理令牌。这个 App 只是看板，不自带服务器，也不提供任何探测别人服务器的能力。

后端源码、部署方式与接口文档在私有仓库，安装包本身不含任何服务器地址或凭据。

## 更新说明

每个版本的改动写在对应的 Release 里。App 内「检查更新」读的是最新 Release，不消耗 GitHub 接口额度。

## 关于

- 不做后台常驻，通知走系统；小部件刷新由系统调度。
- 不收集、不上传使用数据。配置与你添加的服务器信息只存在本机，令牌用系统加密存储。
- 安装包已开 R8 与资源瘦身，大小约 4 MB。

## 许可

客户端为私有软件，安装包可自由下载与使用，不提供源码。
